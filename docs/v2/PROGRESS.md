#### Decisions Made
- **measurements.toml round trip is semantic, not byte-exact.** notch's file carries a ten-line prose header and comments between tables; rows cannot reproduce prose. `checkout` quotes every measurement key and preserves each stored unit, so non-mm imports remain non-mm and `measured()` refuses them instead of building mislabeled geometry. The test compares `tomllib` parses. Part sources and cards stay byte-exact.
- **Shared modules preserve where Python imports them from.** Root `*.py` files use `kind = "module"` and materialize at the project root; `parts/_*.py` files use `kind = "parts_module"` and return to `parts/`. Rows are unique by project/name/kind so both locations may carry the same basename. The name regex applies to parts only; both module kinds require Python identifiers, and parts modules also require the leading underscore.
- **The project's printer choice is the raw `printer.toml` text** (`projects.printer_toml`, nullable), materialized verbatim. A single profile-name column would drop `[printer]`, `[part]`, `[accepted]` and `[export]` tables a v1 folder may carry. `profile` is parsed out when a caller needs the name.
- **`build_runs.error` holds the trimmed traceback** for unexpected exceptions (hosted.py splits `error` and `traceback`; one column is enough here) and the bare message for `registry.Rejected`.
- **Connection order:** connect with `autocommit=True`, set WAL, `synchronous=NORMAL`, `foreign_keys=ON`, and `busy_timeout`, then remain in autocommit. Row helpers use explicit `BEGIN IMMEDIATE` transactions, including nested participation in an import's outer transaction. Migrations use their own explicit transaction around each `PRAGMA user_version` step.
- **Scratch folders live at `<NURB_HOME>/scratch/<project_id>/`**, one per project, cleared as a snapshot (`parts/*`, root `*.py`, `measurements.toml`, `printer.toml`) on every materialize.
- **`project_id` is `NOT NULL` on every child table.** The first spec omitted it on `measurements`, `messages` and `pinned_specs`; corrected before the migration ships.
- **`import_folder` is one explicit outer transaction.** Row-helper transactions participate without committing when already nested, so any failed file or measurement rolls the project and every partial child row back together.

#### Decisions Made
- **The SDK is mcp 2.x, and the plan's v1 names are gone.** `uv add mcp` resolves to 2.2.0. Handlers are constructor kwargs on `Server` (`on_list_tools`, `on_call_tool`), attributes are snake_case with camelCase aliases, the in-process test transport is `Client(server)`, the HTTP client helper is `streamable_http_client`, and `httpx2` replaces `httpx`. Raising inside a handler is a JSON-RPC protocol error, so the dispatcher catches everything and returns `is_error`.
- **Only `mcp` is declared.** starlette, uvicorn, jsonschema and httpx2 are hard dependencies of the SDK's own Streamable HTTP transport, so they cannot disappear without the SDK breaking itself. Declaring them separately would be four version pins for zero safety.
- **`edit_part_source` is an exact-text replace** (`old_string` must match once), mirroring nurb-app's field-tested tool, not the AST keyword edit the plan named. The AST edit is what sliders use and belongs to the workbench write side in Phase 10. Python must use `str.replace(old, new, 1)`, never `re.sub`, because part sources contain backslashes.
- **Every tool takes `project_id`.** The server is stateless and one database holds many projects; the hosted app scoped tools to a conversation, which does not exist here. `list_projects` and `create_project` hand the id out.
- **A failed build is a result, not a tool error.** `write_part_source` on a part that raises returns `isError` false with the trimmed traceback in `error`, so the model reads it as a build to fix. `isError` is reserved for bad arguments, missing parts and unimplemented tools.
- **Build results link the GLB, not a render, until Phase 3.** The `ResourceLink` points at `{base_url}/glb/{project_id}/{part}.glb`; Phase 3 swaps it for the render resource.
- **Placeholder project names are nurb-app's shop-floor word list** (thirty adjectives, thirty-two printing terms), ten random draws before falling back to a count.
- **`json_response=True` drops progress notifications.** Stateless JSON mode has no back channel, so build tools cannot stream progress. If a long build ever needs it, that is an SSE-mode decision made up front, not a tweak.
- **The proxy lives in `nurb_entrypoint`, not `nurb`.** Importing any submodule of `nurb` runs `nurb/__init__.py`, which imports build123d: 4.1 s measured, paid at every agent session start for a process that only moves JSON. `nurb_entrypoint` already exists for commands that skip OCCT, so the proxy spells out `home()` itself and a test asserts it agrees with `db.home()` and that `build123d` never enters `sys.modules`.
- **The lock is per database, not per port.** A second `nurb serve` with any `--port` defers to the running one and prints its URL.
- **Tool calls run in a worker thread under one lock.** Builds take seconds and must not block uvicorn's loop; the single sqlite connection is opened with `check_same_thread=False` and every handler takes the same `threading.Lock`.

#### Decisions Made
- **The rasterizer keeps the z-buffer.** The plan says "painter's order"; nurb-app tried centroid sorting and a pocket floor streaked over a nearer top face. The rails regression test comes across with the port.
- **Labels in the picture, captions in the text.** The composite letters the view names in uppercase from a built-in 5x7 bitmap font at 2x; the four caption sentences and the reading note travel in the JSON payload as `views` and `look_note`. Lettering full sentences in a bitmap font would cost pixels the vision model cannot read anyway.
- **The composite is RGB on white; per-view resources stay RGBA on transparent.** Vision pipelines render alpha unpredictably, and the composite is for the model; the per-view renders keep nurb-app's card contract for a future library thumbnail.
- **Resource URIs carry the project id**: `nurb://render/<project_id>/<part>/<view>`. Part names are unique per project only, and every tool already takes `project_id`.
- **The build result's ResourceLink points at the full-size iso render**, replacing the GLB link. The `/glb/` HTTP route stays for the viewer in Phase 9.
- **Per-view renders are rasterized on demand from the stored GLB** when a resource is read; only the composite is stored, in `build_runs.render`. A render failure never fails a build: the row stores NULL and `look` backfills.
- **`inspect --render` and `verify --report` keep working through the rasterizer** with the camera still aimed at each finding's face, but without the viewer's finding highlight. Both commands are v1 CLI surface that Phase 10 revisits; losing the highlight now is cheaper than porting it.
- **`--section` is a mesh cut** (trimesh `slice_plane` with a cap), keeping the half on the far side of the camera so the picture looks into the cross-section.
- **CONTRACT §2's composite ceiling becomes 80,000 base64 characters**, matching the measured gate in the plan, since the contract file is the coordination point.
- **A render failure never fails a build.** `run_build` stores NULL in `render` and a one-line `render_error` in `stats`; the build result then carries the link without the image, since the resource path can still rasterize the view on demand.

#### Rendering behaviors kept from v1 (`src/nurb/viewer.html`, noted before porting)

- Camera: "a rebuild is a geometry swap, never a camera reset"; the fit is `dist = span / (2 tan(fov/2)) * 2.1` along iso `[0.7, -0.75, 0.6]`, near `span/100`, far `span*100`; a restored camera is accepted only when `sane(p, t, box)` holds (not inside the box, target within `2*span`, distance in `[span/100, span*50]`) and the frustum intersects the box; persisted state is `{p, t}` only (1723-1804).
- Materials: `MeshStandardMaterial` with `polygonOffset 1/1` so the edge overlay does not z-fight; a failed rebuild dims the last good mesh in place rather than removing it (823-836, 1859-1866).

## Architectural Decisions
- Phase 13: an ACP session gets the nurb server as an HTTP entry when the adapter advertises `http`, else untagged stdio; whether the tools reached the model is a cached verdict per adapter version, decided by one probe that calls `list_projects`; a session whose adapter cannot reach the tools works in a checkout folder under the project dir and every changed part file is POSTed back to the serve, which is still the only writer of rows; Codex runs in codex-acp's full-access mode because the app's Seatbelt profile is the guard and a sandbox cannot nest.
- Phase 10: anything that needs the solid runs as a worker op (`build`, `export`, `stress`) under one fault containment; results derived from a build are columns on its `build_runs` row so a rebuild clears them by construction; the page owns the debounce and the sequence guard for slider builds and never touches the viewer directly, the refetch does.
- Phase 9: the serve is the only process that shapes rows for a page; the API returns UI-ready `Message` objects and `BuildEvent`s so neither the workbench nor the desktop shell learns tool names. Change events are ids only and the page refetches; deltas are not applied in the browser.
- **The viewer is a component, not a document.** `ViewerIsland` owns renderer, scene and controls behind props; the caller keys one mount per part and persists the camera through `camera` and `onCamera`. No iframe, no `postMessage`, no `localStorage` in the package (Phase 7).
- **Plating is measured in world space and stored in the parent's frame.** The root group rotates a part whose print-up is not Z; the shift that centers it and drops it onto the bed is computed after that rotation and written back through the inverse quaternion (Phase 7).
- **`@nurb/ui` ships Tailwind source, not compiled CSS.** Components carry utility classes as literal strings and `tokens.css` is a Tailwind 4 source file; a consumer runs Tailwind and adds `@source` for the package. The desktop adopts Tailwind when Phase 11 rebuilds its shell on the package (Phase 6).
- **Card types are narrow and mirror `nurb serve` rows.** `BuildEvent`, `ToolStep`, `Finding`, `Spec`, `Measurement` and `Message` in `packages/ui/src/types.ts` replace nurb-app's all-optional `EventPayload` union; the workbench (Phase 9) maps server rows onto them (Phase 6).
- **Rows are the truth; the engine still builds a folder.** `materialize.py` regenerates `<NURB_HOME>/scratch/<project_id>/` before every build so `builder`, `checks` and `measured()` stay exactly as v1 shipped them (Phase 1).
- **Shared module rows retain their import location.** Root `*.py` files use `kind = "module"`; `parts/_*.py` files use `kind = "parts_module"`. Both locations may share a basename because row uniqueness includes `kind` (Phase 1).

- **One process owns the database, and `nurb mcp` never opens it.** `nurb serve` holds `serve.lock` for its lifetime and publishes `serve.json`; the proxy and any second serve read that file and defer (Phase 2).
- **`tools.json` is the runtime tool list, not a copy of one.** `list_tools` serves the file through `Tool.model_validate`; the contract test proves the SDK round-trips it byte for byte, and the dispatcher's handler table is pinned to its names (Phase 2).

## Lessons Learned
(One lesson per entry with a one-line summary. Record corrections and confirmed approaches alike, including why they mattered. Do not duplicate what the repo or docs already record. Update an existing lesson rather than adding a near-duplicate. Delete lessons that turn out to be wrong.)

- **A test whose expected value the code would produce anyway cannot fail.** The camera-keep test compared the matrix after framing the same shape twice; the reviewer deleted the keep path and all tests passed. Move the state somewhere the code would not put it on its own (orbit first), then assert it survived.
- **A React-owned canvas dies with StrictMode's first cleanup.** `forceContextLoss()` on unmount is right, but a lost WebGL context cannot be reacquired on the same element, so the second mount draws nothing. Let the renderer create its canvas and append it; the screenshot caught this, the DOM checks did not.
- **A shift measured in world space is not a local position.** `Box3.expandByObject` reads `matrixWorld`; writing that shift to `position` under a rotated parent rotates it a second time. Convert through the parent's inverse world quaternion, and test with a non-identity `up`.
- **`controls.update()` emits `change`, so programmatic framing looks like a user orbit.** A parent persisting `onCamera` would save a pose nobody chose. A `quiet` flag around the component's own camera writes keeps the callback honest.
- **Effects that share a render race an async load.** Findings arriving with a new `glbUrl` were placed by the previous part's shift. Gate the sibling effect on the load generation the scene actually shows.
- **Context7 answers a WebGL stencil question with the WebGPU example.** `ClippingGroup`, `stencilWriteMask` and `InvertStencilOp` are the TSL path and silently do nothing under `WebGLRenderer`; the r185 `webgl_clipping_stencil.html` two-pass recipe is the one to port.
- **The glow verifier counted 969 colors; the section verifier counted cap pixels at the lit color, not the palette hex.** A lit `MeshStandardMaterial` never paints its nominal color, so pixel evidence has to name the shaded value.
- **A state test that mounts the end state proves nothing about the transition.** "Starts a failed step open" passed while a step that failed after mounting stayed shut, because `useState` read the status once. Test the rerender from running to failed, not just the failed mount.
- **A prop copied into state is a prop that stops working.** BuildCard held `collapsed ?? passed` in state and an effect overwrote the caller's `collapsed={false}` on mount. Pass it through to the component that owns the open state.
- **The engine reports only what is wrong.** Findings are fail and warn, never pass or info, so a "N checks pass" count derived from the finding list is always zero and the type must not promise `info`.
- **`agent-browser screenshot <selector>` paints a blank frame for anything below the fold.** Every per-element capture came back one color (`#ffffff`) at the right size, even after `scrollIntoView`; two fresh-context verifiers caught it by counting distinct pixels. Capture `--full`, read the element's rect through `eval`, and crop with Pillow. Count colors before calling a PNG evidence.
- **Vitest with `globals: false` never registers Testing Library's auto-cleanup.** A second `render` in one file finds two copies of the component. Each suite calls `afterEach(cleanup)`; the setup file is the better home once every suite needs it.
- **A live counter inside a `<button>` is part of its accessible name.** The `Elapsed` leaf needs `aria-hidden` like the other visual spans, or a screen reader hears "4.2s Check bracket, running for 3 seconds". `agent-browser snapshot -i` shows the computed name and is the cheapest check.
- **Fontshare's ITF license is a use license, not a redistribution one.** Satoshi may not be "made available to any other person", which rules out a public repo and an npm tarball; only OFL faces ship in the package. Check a font's license before a plan line says "shipped in the package".
- **A "port" can have nothing to port.** The manifest agent found nurb-app's `MeasurementCard` has no accept or edit and its build steps carry no verb, object or timing; both were designed here from references instead. Read the source inventory before writing contracts that assume it.
- **sqlite3 PRAGMA order is load-bearing and fails silently.** `PRAGMA foreign_keys=ON` inside a transaction is a no-op with no error and `journal_mode=WAL` raises. Connect with `autocommit=True`, set every pragma, stay in autocommit for fresh reads, and wrap writes in explicit transactions. `tests/test_db.py` asserts `foreign_keys == 1` so a reorder is caught.
- **OCCT faults can carry an empty message.** `Box(w, w, 0)` raises `Standard_Failure` with `str(exc) == ""`. Storing only `f"{type}: {msg}"` would leave the user with nothing; the trimmed traceback is the diagnostic and is what `build_runs.error` holds.
- **`parts/_helper.py` needs a distinct stored kind.** `parts_module` preserves that import location through materialize and checkout instead of flattening it into the root with ordinary `module` rows, including when a root module has the same basename.
- **nurb-app's `part_revisions.params` column is dead.** Nothing writes or reads it; the params list lives on `build_runs.params` because it is a property of a build. Keep the column here for schema parity but do not design around it.
- **mcp 2.x raises are protocol errors, not `isError`.** A handler that raises answers JSON-RPC -32603 and the model sees "Internal server error". The dispatcher catches everything and returns `is_error=True` with a sentence; the SDK also validates nothing against `inputSchema`, so `jsonschema` in the dispatcher is the only guard.
- **`manager.run()` must be the Starlette lifespan, once per instance.** Without it every request answers "Task group is not initialized"; a mounted sub-app's lifespan never runs, so the parent app owns it.
- **`json_response=True` has no back channel.** Stateless JSON mode drops notifications and cannot elicit or sample. Build progress, if ever wanted, means SSE mode chosen up front.
- **Anything imported from the `nurb` package pays 4 s of OCCT.** `nurb/__init__.py` imports build123d. Per-invocation, non-CAD entry points belong in `nurb_entrypoint`.
- **A stale `serve.json` is not a running serve.** SIGKILL leaves the file behind. Readers verify `/health` before trusting it, and the proxy compares the new file against the dead one it found.
- **`str.replace(old, new, 1)`, never `re.sub`, for `edit_part_source`.** Part sources carry backslashes that a regex replacement would interpret.
- **The proxy's upstream connection must live in its own task.** anyio cancel scopes belong to the task that entered them; closing a dead MCP client from a handler's task leaves a scope behind that cancels the next connect. Requests reach the connection task over a zero-capacity channel, and the in-flight request is an attribute, because a session that dies raises out of the SDK's task group as an exception group and the loop has to know which request to fail.
- **A serve's `/health` is only proof of that serve when the pid matches.** Two homes on one machine (a developer's and the app's) pick from the same port range, so a dead serve's port can be taken by a live one for another database. The proxy checks the pid `/health` reports against `serve.json`.
- **`latest_run` has two meanings.** Staleness and the GLB route want the newest run of any revision; `get_project` and `read_findings` want the current revision only, or a revision whose build crashed before its row landed reports the previous source's passing build as the current state.
- **uvicorn re-raises SIGTERM after its own shutdown.** It restores the original handler and raises the signal again, so with `SIG_DFL` the process dies before `uvicorn.run` returns and a `finally` never runs. SIGINT only works because the default handler raises `KeyboardInterrupt`. Install a SIGTERM handler that raises `SystemExit`.
- **`secrets.compare_digest` refuses non-ASCII str.** Compare header bytes, never a decoded header, or an unauthenticated request is a 500 with a traceback.
- **A test's own child is a zombie until reaped, and `kill(0)` still answers.** Assert on the port going quiet and the state file vanishing, not on the pid.
- **Claude Code passes MCP `ImageContent` through as a native image block.** Measured on 2.1.270 with a 44,488-character composite: the raw `stream-json` shows `{"type": "image"}` inside the tool result, no cap error, and the model describes the picture. The GitHub reports of images counted as text did not reproduce; keep the measured gate anyway, since the plan's 80,000 ceiling is what was tested.
- **Flat-shaded PNGs want filter 0.** Adaptive Sub and Paeth filters turn long runs of one tone into deltas that zlib matches worse; 33 to 39 percent larger on these frames.
- **trimesh's capped `slice_plane` needs shapely.** Without it both cap modes raise; `trimesh.intersections.slice_faces_plane` clips without it, and painting the back faces in the cap's tone closes the shell in the picture.
- **A cut reframes, so "fewer painted pixels" is a false assertion.** The camera fits the smaller mesh and the half fills more of the frame; assert on the geometry's bounds instead.
- **Spawn-based engine workers re-execute an unguarded driver script.** Ad-hoc scripts against `engine_run` need `if __name__ == "__main__"` or the child re-runs the script and the build reports "the CAD engine stopped".
- **Multi-line prompts to `claude -p` go over stdin.** A quoted multi-line argument was read as no prompt at all.
- **Only `MCPError` crosses the wire with its message.** mcp 2.x logs any other exception from a resource handler and answers a bare "Internal server error"; the in-process `Client(server)` does not show this, so a resource refusal has to be an `MCPError` and has to be checked through the proxy.
- **Every MCP method the serve answers needs a line in the proxy.** `list_resource_templates` was added on the serve and forgotten in `nurb mcp`, and in-process tests cannot catch that. Drive new methods through `StdioServerParameters(command=nurb, args=["mcp"])`.
- **An image test that never decodes the image tests nothing.** Assert on decoded pixels; a 20-line filter-0 decoder is enough for `encode_png`'s output.
- **A port from Ruby needs its type checks re-read, not translated by feel.** `value.is_a?(Numeric) && !value.is_a?(Integer)` became `isinstance(value, (int, float))` and let an int default through on a float param, which is the exact slider bug the doctrine warns about. A fresh-context verifier caught it; the implementer's own parametrized test had skipped that case.
- **Noise images are the wrong fixture for a size budget.** Random pixels do not compress, so every test case shrank to the floor and the plain 800 px path was never exercised; use a gradient for the common path and keep noise only for the shrink case.
- **Pre-wire the dispatcher before parallel implementers touch one file.** `HANDLERS` naming functions that do not exist yet makes the module unimportable until the last agent lands; each agent had to test against a stubbed copy. Next time leave the names out of `HANDLERS` and have each agent add its own line.
- **An attachment's name is its path below `references/`, never its basename.** Upserting on `(project_id, name)` with a basename made sibling folders with one file name a silent last-writer-wins; the reviewer caught it, the tests had only flat folders.
- **`claude --safe-mode` silently drops every `--mcp-config` server.** Measured on 2.1.270: the init event says `mcp_servers: []`, no error anywhere, and the model goes hunting with Bash. Any harness that carries the flag cannot attach nurb; check the init event's `mcp_servers` before trusting a transcript.
- **A model with no tools and Bash will find the tools anyway.** In an empty directory with permissions skipped, Fable read `ps`, found the trial's `mcp.json` path, imported the package and drove the database by hand, then reported success. A gate that means "through the tool path" has to remove the other paths, not just leave them unmentioned.
- **Force a default with `setdefault`, not assignment, after recursing into the same key.** `strip` had already rewritten `additionalProperties` as a sub-schema and then clobbered it to `false`; latent today because every object in `tools.json` is closed.
- **npm refuses a prerelease without `--tag`.** `npm publish` of `1.0.0-alpha.1` fails with "You must specify a tag using --tag when publishing a prerelease version"; the job derives `next` from a `-` in the version so an alpha never lands on `latest`.
- **Trusted publishing cannot do a package's first publish.** The npm trusted-publisher settings live under the package's own settings page, which does not exist until the package does. The first upload needs a token; the trusted publisher replaces it afterwards.
- **`npm view pkg@version version` exits 1 for a missing version on npm 11.** Measured on `react@99.99.99`; the workflow's existence check relies on it, so re-check if the CI npm major changes.
- **The verifier's literal reading of "exactly" is the cheap fix's trigger.** The export-set test asserted one more name than the contract listed; the right move was one word in CONTRACT §3, not loosening the test.
- **A scroll cap on a reference layout has to fit the fixture.** `max-h-40` on the findings list hid the fourth row in the still that Phases 9 and 11 copy; read the last row's rect against the list's before calling a capture done.
- **`agent-browser` sets the viewport under `set viewport W H`.** There is no top-level `viewport` command; the full-page capture at 1440x1000 still paints the WebGL canvas, so the Pillow crop path from Phase 6 holds for canvases too.
- **Green tests and a clean screenshot missed ten usability defects that one live drive found.** Duplicate ids across two panels, a note far from the button it answers, a control with no focus ring, a select inside `role="menu"`: none of them fails a unit test or shows in a still. Drive the real page with the console open before calling a surface done, and count `[id]` collisions on any page that mounts a component twice.
- **A gallery host has to model the host's half of a contract.** `ParamsPanel` cannot clear its own dirty state because the host owns the defaults; a gallery `onApply` that only shows a note leaves the panel saying "1 change" under "Saved". Fixture hosts write the defaults back the way a real one would.
- **`git mv -k` exits zero when it skips.** On an untracked file it moves nothing and the `|| mv` fallback never runs; the next build then fails on a path that looks right. Use plain `mv` for untracked files.
- **A version bump is a behaviour change wherever a version is parsed.** `1.0.0a1` silenced both nudges because `_newer` cast dot-separated parts to int, and only the full suite caught it; the focused `-k version` run in the phase's own criterion never touches `server.py`. Grep for every place a version string is compared before bumping to a prerelease.
- **A live region that mounts with its text may never be read.** `role="status"` has to exist before the message arrives; keep it mounted and empty (`sr-only`) and change its content.
- **A geometry swap spends OrbitControls' leftover damping.** Damping decays the spherical delta but never zeroes it, so the first render after a rebuild nudged the stored pose by a float and the readout flipped a digit. Zero the delta once `controls.update()` reports the controls parked; the matrix-equality test could not see it because it never orbited with damping running.
- **`@nurb/ui` resolves through `packages/ui/dist`, so the workbench build ships whatever dist holds.** A viewer fix followed by `npm run build --workspace packages/workbench` alone produced a false "fixed it"; build `packages/ui` first, every time.
- **A transcript that pins itself on mount pins against a container the fonts have not sized yet.** `scrollTop = scrollHeight` ran before the cards had their height; one `requestAnimationFrame` later it holds.
- **A full-page capture of a page that never scrolls is the wrong capture.** `body.scrollHeight` counted the transcript's clipped overflow, so `--full` painted a blank band and Chromium's relayout reset the transcript's `scrollTop`; capture the viewport when `documentElement.scrollHeight` equals the viewport.
- **A CDP mouse drag needs waits between moves.** A fast batch of move events registered no orbit at all; spacing them by a few tens of milliseconds did.
- **An empty findings list is not a pass.** A part that never built and a build that crashed both arrive with `findings: []`; copy that reads the list as a verdict contradicts the header. Derive the verdict once from the build status and hand it down.
- **Two refetches a millisecond apart need a sequence guard.** One build emits `part`, `build` and `message`; the page fetched the project three times and nothing ordered the answers. A counter per loader, checked after the await, drops the late one.
- **A stored value that passed `Array.isArray` still blanked the page.** Strings inside the array reached `toFixed` and React unmounted the tree. Validate the elements, not the container, and keep a poisoned-storage case in the test.
- **Grep for a name cannot find a module reached through another module's import.** Deleting `nurb dev` looked complete until a serve-level test started `nurb serve` and it died: `serve.py` imported `_is_free` and `DEFAULT_PORT` from `cli.py`, which no grep for `dev` or `launcher` shows. Keep one test per process that starts it as a subprocess.
- **A run row is the cache key.** Stress and slice results stored as columns on `build_runs` clear on rebuild without any invalidation code, because a rebuild is a new row; the page keys its tiles on the run id and needs no event for it.
- **`add_revision` drops the card unless told otherwise.** Its `card_md` defaults to `None`; every writer of a revision that is not a card edit has to carry the current card forward, as the apply route does.
- **A worker op is the only place the B-rep exists.** v1 kept the live shape in memory so export and stress were cheap; v2's worker returns only bytes, so anything that needs the solid rebuilds inside the worker under the same fault containment. A route that rebuilt in the serve thread would have skipped it.
- **Override builds ignored card variants until a ported test said so.** `engine_run` called `checks.from_card`, which reads only the `[part]` block; `checks.configurations` knew the variants but only the CLI reached it. Porting the v1 invariant as a strict xfail first, then closing it, kept the gap visible instead of silently lost.
- **A components map rebuilt on every render makes react-markdown detach its nodes.** A `findByText` resolved and `toBeInTheDocument` then failed one run in four; hoisting the map to a module constant fixed it. Any `components=` prop deserves a constant.
- **A flex sibling with `flex-1` and basis 0 loses to a sibling without `flex-1` and large content.** The rail's measurements block ate the whole column at 900px and the parameters panel measured 0 height; every verifier had to raise the viewport to 1200 to reach Apply. Cap reference blocks, and read the write surface's height at a laptop viewport before calling a rail done.
- **A never-built part is a dead end unless the page can build it.** Four of five browser verifiers had to seed the first run with curl. The empty state now carries a Build button and the params route accepts empty values with no prior run.
- **`json.loads` accepts `NaN` and `Infinity`, and Starlette's response refuses them.** A non-finite slider value passed validation, spent the whole build deadline under the serve lock, was stored, and then every project read answered 500 forever. Any number that reaches OCCT or a row needs `math.isfinite`, and an int beyond float range raises `OverflowError` on the check itself.
- **A React key on a value that changes under the user resets what the user was doing.** Keying the download menu on the run id made every slider build close the menu and drop the prepared file. Key on identity (the part) and invalidate through a prop.
- **A deleted module can come back under a new name in a review.** The silent exit 139 was real, but the fix offered was the crash module's ctypes handler again. The stdlib `faulthandler` covers the actual defect in two lines; check the size of a fix against the size of the hole.
- **`tauri://localhost` is a secure context, and `ws://localhost` is insecure there.** The bundled app's page threw `SecurityError: The operation is insecure` from the `WebSocket` constructor inside the live hook's effect, React unmounted the tree, and the window was blank with nothing in any log. Loopback by IP (`ws://127.0.0.1`, `http://127.0.0.1`) is exempt in WKWebView; `localhost` is not. A page not served over http waits for `configure` before opening a socket, and the constructor's throw is caught and retried like a dropped socket. Vite never showed this because the dev page is `http://localhost:1420`; verify the bundle, not only `tauri dev`.
- **A blank bundled page has no console; make the webview answer from Rust.** `window.eval` through the debug hook (`eval:<js>` on 7399, answered by a `debug_log` command that prints to stderr) runs even when the page's own script never mounted, and the bundle's binary run from a shell keeps its stderr. Re-importing the entry module with an `error` listener armed produced the stack in one probe after twenty minutes of guessing at CSP.
- **`tauri dev` with `devUrl` removed serves the page from `http://127.0.0.1:1430`, not `tauri://localhost`.** Its CORS and secure-context behaviour differ from the bundle in both directions, so it proves nothing about the bundle.
- **`open` on a URL scheme brings the app to the front; `open -g` does not.** One warm-link test stole focus before the flag was used; every later launch used `-g`.
- **A hook effect keyed on data re-subscribes on every refetch.** The desktop's test-hook listeners and console patches lived in an effect whose deps included the project list, so each bus event stacked another listener and another wrapper; one rejection printed three times and every teardown threw. Subscribe once and read live data through a ref.
- **A read method is not a read.** The slice route did a materialise, a slicer spawn and a database write behind GET, and the same-origin guard exempts GET by design. Classify routes by what they do, not by what they return.
- **Validate a foreign payload once, at the boundary, and pin what you asked for.** `adopt` trusted seven fields from nurb.app's JSON and each missing one was a traceback; the slug the server answered with can differ from the one requested and can fail the part-name rule. `fetch` checks the shape and keeps the requested slug.
- **A singleton socket opened before the base is known never finds it.** The desktop learns its serve's port asynchronously, but `useLive` subscribed on first render and the socket went to the page's own origin; Vite never answered the upgrade, so `onclose` never fired and the retry-with-`resolve` path never ran. A host that configures late has to say so (`reconnect()` after `configure`); a verifier saw it as "delete does not refresh the rail" because the hook-driven paths refetch directly and hid the dead bus.
- **A dev app restarted by the file watcher can lose its debug port.** The old instance lingered as an orphan holding 7399, the new one's bind failed silently, and hook events went to a page that no longer had the new arms. Check `lsof -iTCP:7399` against the live pid before driving the app.
- **`SIGTERM` to the Tauri process does not run `RunEvent::Exit`.** The serve child in its own process group survived the app; the next app adopted it as external. A quit from the menu runs the hook; a signal does not, so the serve wants a parent-pid watchdog of its own (noted, not built).
- **A route that reads only the newest run forgets everything a failed build could not report.** One exception before the signature was read erased the sliders and refused every later build. Fall back to the newest run that carried the data.
- **`claude -p` with stream-json input says nothing until the first user message.** Not even `init`, only the SessionStart hooks; the init line belongs to the first turn. A driver that waits for the session id before it lets a prompt through deadlocks with a silent child, and the fake-CLI test (`read line; cat fixture`) modelled the wait correctly while never exercising the function that waited. Mint the id with `--session-id` and return at spawn; test the glue that waits, not only the mapper.
- **A fully occluded WKWebView paints nothing, and `screencapture -l` returns white.** `document.hidden` through the eval hook is the check; `perform action "AXRaise" of window 1` through System Events un-occludes it without making the app frontmost, and the capture works the next second. Do not read a blank capture as a blank page.
- **`pkill -f "tauri dev"` kills npm and leaves Vite on 1420.** With `strictPort` the next `tauri dev` fails its `beforeDevCommand` and the app never appears; kill the 1420 listener first (the app's own `kill -9` takes Vite with it).
- **A transcript row that stores only a tool name renders "Get null".** The verb came from the name, the object from a summary the event row never had. Store what the reader needs (subject, the refusal) at write time; deriving it later has nothing to derive from.
- **A column seeded with `resume: null` never resumes, for any agent.** Phase 11 stored the session id on every turn and read it back nowhere; the resume path only ever ran inside one app session. A criterion that says "relaunch" has to be run with a relaunch.
- **A sandboxed adapter cannot sandbox itself.** Codex wraps every command and every `apply_patch` in its own `sandbox-exec`, and macOS refuses a nested `sandbox_apply` (exit 71) inside the app's Seatbelt profile. Shell commands limped through on Codex's escalation path, which is why nothing failed visibly for a phase, but file edits have no escalation and died with a "permissions error" the model paraphrased. The adapter's own rollout transcript under `~/.codex/sessions/` carried the exact error when the app's log and the system log showed nothing; read the agent's own record before theorising.
- **An enumeration prompt cannot prove a tool reached Codex.** Codex loads MCP tools lazily behind a search step, so a model with the server connected still answers "none"; asking it to call the cheapest tool, and telling it to search first, is the only probe that held.
- **A migration that has run never runs again, so never edit one.** `CREATE TABLE project_files` was appended to migration 1 after databases sat at schema 2; migration 3's `ALTER` then failed forever and the app showed "Starting the engine" with no hint. The fix is a `CREATE TABLE IF NOT EXISTS` in the migration that first needs the table; the rule is a new migration for every schema change, even on an unreleased branch, because the developer's own database is already at the old number.
- **The Tauri dev watcher rebuilds the whole app on any Rust save, and that kills every ACP session in flight.** A verifier's two Codex turns died to a sibling agent's `supervisor.rs` edits. Finish the Rust before a live desktop drive, or run the drive against a `tauri build --debug` bundle.
- **A remembered value the app never asks for is not remembered.** The serve learned to reuse its port, but the supervisor passed `--port` from its own walk on every launch, so the app (the primary path) rewrote the saved port each time. Trace who chooses a value end to end before calling it stable; the reviewer found it, the serve tests could not.
- **`isinstance(x, int)` admits `True`.** A saved port of `true` passed the range check and bound port 1. `type(port) is int` for a value that came from JSON.
- **The Codex CLI cannot take a header from `codex mcp add`.** Only `--bearer-token-env-var`; a per-app token has to go into `config.toml` as `http_headers`, so the copyable line is a `printf >> ~/.codex/config.toml`, not an `add`.
- **A Cursor deeplink's `config` is the inner server object, base64, and needs percent-encoding.** The docs' prose shows the `{name: {...}}` wrapper but their own example decodes to the bare object; standard base64 padding and `+` do not survive a query string unencoded.
